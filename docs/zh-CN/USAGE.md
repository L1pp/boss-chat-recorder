# 使用指南

[English](../USAGE.md) | [简体中文](USAGE.md) · [文档导航](README.md)

本页说明仓库源码的界面。商店版可能仍是较早的界面，发布沿革见[更新记录](CHANGELOG.md)。

## 安装

从 [Chrome Web Store](https://chromewebstore.google.com/detail/phaihpchfdihnclgjhpmpnhobdcogdhb) 安装。

从源码加载时，按[构建说明](TESTING.md)生成扩展，打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，指向 `extension-tracker/`。更新时重新加载原有安装。不同安装和浏览器配置使用各自的归档，不会自动互相导入记录。

## 采集和更新

1. 正常登录自己有权使用的账号，打开 [BOSS 沟通页](https://www.zhipin.com/web/geek/chat)。
2. 打开扩展。新归档使用“开始首次采集”，之后用“更新变化会话”，中断后用“继续上次采集”。
3. 保留沟通页。关闭扩展弹窗不影响后台采集；刷新或关闭沟通页会中断，已保存记录保留。

界面账号表示本地归档，不是重新查询的网页登录状态。启动采集按网站当前账号处理，导出和备份处理所选本地归档。如果正常会话列表尚未出现，请先等待页面加载。

## 导出和清除

| 操作 | 结果 |
| --- | --- |
| 导出全部记录 | 当前账号已保存的全部会话 |
| 导出本次更新 | 本轮实际刷新会话的完整已保存上下文；无变化时为空 |
| 备份当前账号 | 当前账号归档及本地更新记录 |
| 清除本地记录 | 只删除该账号本机记录，不删除 BOSS 上的聊天 |

导出文件是明文 JSON；下载不会向 AI 服务发送数据，是否分享由用户决定。本次首次保存的消息也可能是旧历史，不等于今天新发送。未知发送时间保持未知；媒体只保留已有摘要和字段，不下载或解析附件内容。

## 语言

中文浏览器语言使用简体中文，其他或未知语言使用英文；可在弹窗选择“中文 / English”，并在本机记住选择。聊天及导出原文不翻译。Chrome 中的扩展名称和简介由浏览器独立选择语言。

## 暂停与本机数据

遇到人工验证，请在 BOSS 页面完成后再点击继续；扩展不破解验证，也不反复探测验证结果。其他网站或本地保存错误会停止本轮并保留已提交记录，重试前查看错误说明。不要把清除记录或卸载重装作为排查步骤。

新写入的归档数据在本机加密，密钥保存在同一浏览器配置中。旧明文兼容读取，轻量界面元数据不在正文加密范围内；需要保留记录时，请保管浏览器配置和导出备份。详见[隐私政策](../../extension-tracker/PRIVACY.md)和[安全联系](SECURITY.md)。

只能采集网站当前返回的历史；“可获取历史已读完”不代表账号所有时期的历史完整。范围见[验证记录](VERIFICATION.md)。
