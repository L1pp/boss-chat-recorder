# 更新记录

[English](../CHANGELOG.md) | [简体中文](CHANGELOG.md)

本文件记录公开源码的重要变化。内部版本和待发布条目不表示 Chrome Web Store 已发布；带日期的验收证据见 [VERIFICATION.md](VERIFICATION.md)。

## Unreleased

- 增加 Linux、Windows 离线检查，合成数据 Linux Chromium 回归，以及不设覆盖率百分比门槛的 LCOV 报告。
- 增加贡献、安全报告和 issue / pull request 模板。
- 开发文档归入 `docs/`，中文对应版本归入 `docs/zh-CN/`，GitHub 社区说明归入 `.github/`；精简根目录 README 并链接专门指南。

## 0.8.12（待发布）

- 增加首次采集引导、BOSS 沟通页链接与失败重试；按本地归档、续采和人工验证状态展示操作。
- 按账号保留采集历史，避免零记录采集完成后切换标签页又显示首次引导；进度和停止操作仍绑定当前标签页。
- 增加中英文弹窗、以英文兜底的浏览器语言识别，以及本机记住的语言切换；聊天与导出正文保留原语言。
- 开发文档默认英文，保留中文对应版本与互链。

## 0.8.11

- 新归档使用 AES-GCM 与浏览器保存的密钥，无需密码或解锁；旧明文保留兼容读取，不自动转换全部旧库。
- 用户导出的 JSON 仍为明文，不自动向 AI 服务上传记录。
- 使用独立 Chromium 的合成账号验证加密落盘、后台停止/唤醒与浏览器重启后的读取/导出；双真实账号切换仍未验证。
