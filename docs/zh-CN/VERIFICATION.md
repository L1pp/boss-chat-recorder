## 后续导出比对：2026-10-18

归档更新后，诊断状态及全量导出均为 **378 会话 / 3,697 条有消息 ID 的消息**。比对发现 **3 个新会话、63 条新消息，涉及 14 个归档会话**，其中含 1 个平台求职助手会话。原有会话和消息无丢失，身份组合无重复，另有 1 条既有消息的时间字段变化。

这证明后续导出包含自然新增与变化。导出附带的最后一轮元数据为扫描 377、跳过 377、新存 0，不能把 63 条新增全部归因于最后一轮；累计保存的 378 个会话与当轮列表的 377 项也不是同一分母。

只有最终持久化结果算保存确认。活动事件不增加存储轮询、网站请求或定时保活；断线不能撤销已接受的 Chrome 写入，也不自动重发。旧版本与未发布记录会占用空间，直到按账号清除，拆分不表示存储立即缩小。

较早的 0.8.1 真实复验出现 HTTP 200、`text/html`、最终路径 `/web/passport/zp/verify.html`；之后历史请求停止，已保存记录保留。后续中断返回非成功 JSON，用户报告网页/手机端登出。这些只证明已观察到限制，不能确定原因或安全请求速度；10 秒间隔不代表平台认可。

## 复现与剩余边界

当前命令和浏览器覆盖见 [TESTING.md](TESTING.md)。离线测试使用模拟 API、内存 Chrome 存储和临时目录，不访问招聘账号或原项目 `data/`；覆盖分页/原生 ID、增量/重试选择、UID/任务边界、迟到写入、导出、验证暂停和确定性样例。仅把合成演示分目录不构成隔离证据。

- 双真实账号切换仍暂缓。
- 0.8.10 完成阶段未触发线上验证暂停/人工继续；离线测试不能证明当前网站行为。
- 后续 API 兼容性、验证触发规则及平台认可的安全频率未知。
- 大归档容量、长时间断网、浏览器/系统版本和生命周期组合未穷尽。
- 测试、源码公开、商店提交与商店批准是不同事件。
