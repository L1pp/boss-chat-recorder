## 实际纳入的实现

采集基准为原型 **0.7.2 的默认 API 路径**：同源 GET、`historyMsg` 游标分页、原生消息 ID 去重、按 `updateTime` 选择变化会话、批量保存、消息事实模型及 AI 导出。

| 原型基础 | 公开项目新增与适配 |
| --- | --- |
| 联系人列表与历史分页 | 从当前页面读取列表参数，去除个人账号硬编码参数 |
| 会话更新与保存 | 按本人 UID 隔离状态、基线和任务令牌，保留原生消息 ID |
| 异步采集、停止与进度 | 启动时确认一次账号，后续来源及令牌在本机校验 |
| 同源 fetch | 共用固定 10 秒请求间隔，异常暂停并保留已取得数据 |

本项目的存储、界面、导出、合成演示和测试也使用 MIT。存储新增包括按会话版本与账号索引、扩展内部 Port 提交回执，以及浏览器原生 WebCrypto AES-GCM 和 IndexedDB 密钥存储，无第三方运行依赖。

扩展图标设计使用了内置图像生成辅助。透明图稿母版保存在 [`assets/icon.png`](../assets/icon.png)，四种运行时尺寸均由该图缩放生成。
