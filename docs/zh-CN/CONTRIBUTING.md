# 参与贡献

[English](../../.github/CONTRIBUTING.md) | [简体中文](CONTRIBUTING.md)

欢迎使用中文或英文提交问题和 PR。项目及贡献采用 MIT 许可证。仓库由个人在有时间时维护，不承诺响应时限、功能接受或平台支持范围。

## 开始贡献

需要 Node.js 24 或更新版本。环境准备、命令和测试范围见[测试说明](TESTING.md)；打包和商店操作见[发布说明](RELEASING.md)。

## 提交问题与 PR

- 问题报告请包含受影响版本、最小复现、预期行为和实际结果。功能建议请说明具体问题、期望行为及现有替代办法。
- 每个 PR 聚焦一个问题，从分支提交，说明行为变化和验证结果，包括未运行的相关检查。让已配置的 CI 和 AI 审阅按条件运行，并在合并前处理相关反馈；审阅范围见 [AI 审阅说明](AI_REVIEW.md)。
- 改动采集、账号分区、权限、加密或导出时，应补充有针对性的离线测试和隐私说明。
- 使用合成数据和新建浏览器配置。自动检查与演示不得访问真实账号、发送消息、投递简历或绕过平台验证。
- 公开报告和附件不得包含真实聊天、UID、招聘方联系方式、完整导出或 Cookie、验证码、令牌、密钥等凭据。安全漏洞请按[安全问题报告说明](SECURITY.md)私下报告。

## 语言

开发者文档默认英文，并保留互链的中文版本；行为变化时同步更新。中英文界面应保持一致，已保存的聊天正文不做自动翻译。BOSS 名称及有助于说明产品的中文示例可保留中文。
