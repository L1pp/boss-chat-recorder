# 审核备注

[English](../reviewer-instructions.md) | [简体中文](reviewer-instructions.md)

**BOSS 沟通记录本地助手**是非官方的本地归档扩展，最低支持 **Chrome 102**。版本与图片状态见[材料索引](README.md)。

用户在已登录的 BOSS 沟通页手动启动采集，记录按账号保存并导出 JSON。扩展不发送消息、投递简历，也不绕过登录或人工验证。

## 安装与操作

离线测试时，将运行 ZIP 解压到独立目录，在扩展管理页选择“加载已解压的扩展程序”；manifest.json 应位于目录根部。使用单独浏览器配置，避免与日常归档混合。

打开弹窗、刷新本地状态、导出及清除均使用本地记录，不额外请求 BOSS。界面账号表示当前查看的归档账号，不代表重新确认网站登录状态。界面语言初始跟随浏览器，也可在本机切换；聊天正文不翻译。

真实平台测试需要审核人员有权使用的 BOSS 账号：

1. 在网站正常登录并打开[沟通页](https://www.zhipin.com/web/geek/chat)，等待会话列表加载。
2. 打开扩展，启动采集或更新已有归档。请求遵循固定最小间隔，用户可停止任务。
3. 完成后导出全部记录；此操作下载 JSON，不连接 AI 服务。
4. 再次更新时，跳过更新时间未变且历史已读取完成的会话；变化或未完成会话重新读取当前可获取的历史。
5. 遇到网站验证时暂停并保留记录。用户在网页完成验证后手动继续，扩展不自动探测验证结果。

材料不提供日常账号凭据或真实聊天。若无法访问网站，请联系开发者安排适当测试条件，并记录该限制。

## 证据与数据处理

已有合成结果见 [acceptance-0.8.11.json](../acceptance-0.8.11.json)，离线复现及当前浏览器测试范围见[测试说明](../../docs/zh-CN/TESTING.md)。合成检查不能证明真实网站兼容性或双真实账号切换；真实平台范围见[验证记录](../../docs/zh-CN/VERIFICATION.md)。

公开包使用 activeTab、scripting、storage 和 unlimitedStorage。脚本随包提供，不含持续网站权限、远程代码或 localhost 调试桥。请求使用网站已有会话，不读取或导出 Cookie。

新写入的受保护值使用本机 AES-256-GCM，不可导出的密钥自动保存在同一浏览器配置的 IndexedDB，无需密码。UID 键名、轻量摘要、导出 JSON 及保留的旧明文不在加密正文范围内。该保护不提供跨设备恢复，也不抵御控制浏览器配置或操作系统的程序。

细节见[隐私政策](../../extension-tracker/PRIVACY.md)与[填表说明](privacy-disclosure.md)；账号所有者待办和稳定政策 URL 见[材料索引](README.md)。
