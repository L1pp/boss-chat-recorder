# 隐私表填写说明

[English](../privacy-disclosure.md) | [简体中文](privacy-disclosure.md)

本页供填写 Chrome Web Store 后台使用。材料与版本状态见[索引](README.md)，公开披露以[隐私政策](../../extension-tracker/PRIVACY.md)为准。

## 单一用途

用户手动启动后，将其已登录 BOSS 沟通页当前可提供的聊天按账号保存到本机，支持增量更新、导出和删除。

## 权限与远程代码

| 权限 | 可填写的理由 |
| --- | --- |
| activeTab | 用户点击扩展后，临时访问当前沟通标签页，为用户主动启动的归档提供页面上下文。 |
| scripting | 注入随包提供的只读脚本，通过页面已有会话读取账号、会话列表和历史；不发送消息或投递简历。 |
| storage | 在当前浏览器配置保存账号归档、增量基线、进度及不含聊天正文的轻量界面缓存。 |
| unlimitedStorage | 保留的历史、元数据和记录版本可能超过默认本地存储配额；此权限用于本地留存，不用于上传或扩大网站访问范围。 |

公开包不声明持续网站权限，不含 localhost 调试桥，不请求 tabs、cookies、downloads 或系统通知权限。文件下载由用户主动操作。

远程代码：**否**。可执行脚本和模块随包提供，网站接口响应只作为数据处理。

## 数据类型

仅在本机处理的数据也需要披露。请按后台实际类别定义填写，并与软件包和政策保持一致。参见 Google 的[用户数据说明](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)。

| 类别 | 内容与用途 |
| --- | --- |
| 个人身份信息 | 账号 UID、沟通对象标识及返回的联系人资料，用于区分本地账号和会话；聊天也可能包含姓名、电话等。 |
| 个人通信 | 消息正文、方向、时间及接口提供的图片或附件摘要，用于保存、去重、计数和导出。 |
| 网站内容 | 会话、消息及可获取历史的覆盖信息，用于留存可访问记录并说明其范围。 |

扩展不索取密码或验证码，不读取或导出浏览器 Cookie，也不读取浏览历史清单。聊天中的敏感信息随原记录保存，不单独用于画像或分析。

## 存储与保留

新写入的归档、运行态和会话值使用本机 AES-256-GCM；不可导出的 CryptoKey 保存在同一浏览器配置的 IndexedDB。无需密码，不提供跨设备同步或云端恢复；丢失密钥后无法解密。

UID 键名、轻量缓存、计数、部分进度摘要及主动导出的 JSON 或备份可能为明文。旧明文兼容读取，保留的旧副本不自动重写，因此不宣称所有历史副本都已加密。

记录保留至账号清除、卸载扩展、清理浏览器数据或其他存储移除操作。清除不会删除网站聊天或已下载文件；需要留存时，请先导出再清理浏览器配置或存储。

异常诊断仅在本机保留必要的接口路径、状态、响应类型、阶段和计数，不保存 HTML 正文、URL 查询参数或 Cookie。

## 有限用途声明

数据仅用于商品页和界面明示的本地归档、增量更新、导出和删除，并遵循 Chrome Web Store 的 Limited Use 要求。开发者没有聊天接收端、遥测、广告或分析服务。用户数据不出售、不用于广告、不交给无关第三方，也不提供给开发者人员阅读。扩展不向开发者服务器或 AI 服务传输聊天；用户自行分享导出文件由其选择。

提交前确认后台认证项与软件包和政策一致。稳定政策 URL 和账号所有者待办见[索引](README.md)。参考：[隐私表](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)、[隐私政策要求](https://developer.chrome.com/docs/webstore/program-policies/privacy)。
