# 隐私说明

此扩展供用户在自己已登录的 BOSS 直聘沟通页中查看和保存沟通记录。数据保存在当前浏览器配置中的 Chrome 扩展本地存储，不上传到开发者服务器，不使用 Chrome Sync，也不自动发送给 AI 服务。

## 收集与使用

用户打开扩展并启动更新后，扩展在当前沟通页调用 BOSS 页面可访问的同源接口，读取当前账号标识、沟通对象和网站当前可提供的聊天历史。请求使用该页面已有的登录会话；扩展不读取或导出浏览器 Cookie。

本地数据包括账号 UID、会话的原生身份标识、消息内容与时间、分页覆盖信息、更新进度，以及模型分析所需的账号内基线。每个账号分别保存。实际新启动采集时查询一次网站当前账号；已有任务直接返回本机进度，后续保存依据本地任务令牌、来源与原生消息身份校验。查看、导出、备份和清除处理明确指定的本地账号，不为这些本地操作请求网站。账号清除会删除该账号分区，并撤销关联标签页的采集令牌。

弹窗另保存一份不含聊天正文的轻量本地视图，包含上次查看的账号、计数与进度，供下次打开立即显示。它表示本地归档账号，不证明网站当前登录身份。

异常响应的诊断只保留接口路径、HTTP 状态、响应类型和重定向信息，不保存 HTML 响应正文或 URL 查询参数。这些信息与更新进度一同保存在本地，用户主动导出时才随文件离开扩展存储。


识别到网站人工验证页时，扩展按账号保存暂停状态并显示图标角标。用户需在网站自行验证，再主动确认继续；等待期间不自动探测验证结果，不读取验证码或代替用户完成验证。提醒使用扩展自身的角标和弹窗，不申请系统通知权限。

## 导出与删除


0.8.9 在采集启动前于本机整理按 UID 隔离的会话记录，并保留切换前旧根。记录版本和未发布版本均登记在该账号专属清单中；不会自动上传。清除指定账号会处理旧根中的对应分区、该账号会话版本与索引及运行态，不清除其他账号或旧无归属数据。导出仍重组同一账号的完整事实 state。使用新格式后的新增记录不写回旧根，应使用本版本导出。

0.8.8 将进度、任务绑定、账号同步基线与统计摘要单独保存在扩展本地运行态记录中；聊天正文仍在原本地分区中。首次启用仅在本机从原记录提取运行态，不向 BOSS 查询，不删除原聊天。导出会组合当前正文和运行态；清除指定账号仍同时清除其正文与运行态并撤销任务绑定。

用户可主动下载本次更新或全部已保存记录的 AI 分析输入，也可下载当前账号的本地备份。导出文件可能包含个人身份信息及完整聊天内容；用户应自行妥善保管。扩展不会自动打开模型服务或上传这些文件。

“清除当前账号本地记录”只删除该账号在本扩展存储中的状态、更新基线和运行进度，不会删除 BOSS 直聘网站上的数据，也不会删除用户已经下载的导出文件。未分账号的旧版 `bossReadonlyTracker.v2` 数据不会被自动认领或迁入账号分区。

## 权限与限制

- `activeTab` 与 `scripting`：用户在支持的沟通页打开扩展后，读取当前账号并运行用户启动的只读采集。
- `storage` 与 `unlimitedStorage`：在本地保存会话和更新状态。

采集依赖 BOSS 直聘页面及其内部接口，返回范围和字段可能变化。网站当前提供的历史读取完成，不代表账号所有历史完整。此扩展仅用于个人本地记录；使用者应遵守 BOSS 直聘适用的条款和法律要求。

## 联系与变更


公开展示副本不包含本机调试桥、配对令牌输入或 localhost 可选权限。保存 Port 是扩展内部通信，不建立对外连接。
