# BOSS Chat Recorder · BOSS 沟通记录

[English](README.md) | [简体中文](README_CN.md)

[![Automated tests](https://github.com/L1pp/boss-chat-recorder/actions/workflows/ci.yml/badge.svg)](https://github.com/L1pp/boss-chat-recorder/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An unofficial browser extension for saving your BOSS Zhipin conversations locally, updating changed conversations, and exporting JSON for your own analysis.

## Features

- Manually collect the conversation history currently available to your account.
- Update new, changed, or unfinished conversations; resume after a pause.
- Keep separate local account archives, with encryption for new archive data.
- Export all records, the conversations in an update, or an account backup.
- Use Chinese or English, with a remembered language choice.

The extension does not send messages, submit applications, or upload chats to the developer or an AI service. Exported JSON is plain text; keep it private. See the [privacy policy](extension-tracker/PRIVACY.md).

## Get started

1. Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/phaihpchfdihnclgjhpmpnhobdcogdhb), or follow the [source installation guide](docs/USAGE.md).
2. Sign in normally and open the [BOSS chat page / 沟通页](https://www.zhipin.com/web/geek/chat).
3. Open the extension to start collecting. Keep the chat page open, then update or export records as needed.

Only history supplied by the website can be saved. If BOSS requests verification, complete it on the website before resuming.
